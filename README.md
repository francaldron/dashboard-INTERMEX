# Dashboard INTERMEX

Dashboard estratégico y perfil de usuario final de INTERMEX S.A.

## Contenido
- `index.html`: dashboard ejecutivo vigente.
- `netlify.toml`: configuración de publicación estática.

## Flujo de publicación
- Repositorio independiente de `dashboard-ZOFRI`.
- Conectar este repositorio a un sitio nuevo de Netlify.
- Rama de producción: `main`.
- Cada actualización de `index.html` en `main` puede gatillar un nuevo deploy automático en Netlify.

## Base metodológica
Perfil construido a partir de *Disciplined Entrepreneurship*, Step 3: **Build an End User Profile**, pp. 113–121.
